# 📚 Catálogo de Livros com JavaScript

Aplicação web que apresenta um catálogo de livros de tecnologia e permite filtrar, ordenar e calcular o valor dos títulos disponíveis.

O projeto foi desenvolvido durante os estudos de JavaScript para praticar manipulação do DOM, consumo de dados com `fetch` e os principais métodos de arrays.

## ✨ Funcionalidades

- Exibição dinâmica dos livros obtidos por uma API;
- Aplicação automática de desconto nos preços;
- Filtros por Front-end, Back-end e Dados;
- Filtro de livros disponíveis;
- Cálculo do valor total dos livros disponíveis;
- Ordenação dos livros pelo menor preço;
- Identificação visual de títulos indisponíveis.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página;
- **CSS3:** estilos e organização visual;
- **JavaScript:** regras, filtros e interação com o DOM;
- **Fetch API:** carregamento dos dados dos livros;
- **Git e GitHub:** versionamento e armazenamento do projeto.

## 🧠 Conceitos praticados

- `async` e `await`;
- `fetch()`;
- Manipulação do DOM;
- Eventos de clique;
- Template strings;
- Operador spread;
- Métodos `forEach()`, `map()`, `filter()`, `sort()` e `reduce()`.

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/vinicius-antunes/catalogo-de-livros-js.git
```

2. Abra a pasta no Visual Studio Code.
3. Execute o `index.html` utilizando a extensão **Live Server**.

> É necessário estar conectado à internet para carregar os dados da API e as imagens dos livros.
